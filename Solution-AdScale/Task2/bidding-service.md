Bidding Service — Проектирование сервиса ставок

Bidding Service — выделенный микросервис, отвечающий за проведение аукционов: взвешивание ставок, применение бизнес-правил, расчёт победителя. Критичен, SLA P95 ≤ 80–100 мс

Границы сервиса
В Bidding Service входит
Приём bid-request, от API Gateway
Чтение активных кампаний/ставок из Redis
Расчёт победителя аукциона
Публикация данных bid events в Kafka
Запись результатов аукциона в собственный PostgreSQL

НЕ входит
Приём HTTP-запросов от DSP напрямую. (API Gateway)
Управление кампаниями, креативами, бюджетами. (Campaign Service)
Регистрация кликов/показов (Statistics Service)
Финансовые операции (Financial Service)
Формирование HTML/JS разметки (Delivery Service)

Взаимодействие с сервисом
Внутреннее, gRPC API

Зависимости
Redis - Кеш кампаний, ставок, бюджетов.
PostgreSQL - Запись результатов аукциона
Kafka - Публикация bid events
Campaign Service - Получение активных кампаний

Наблюдаемость и логирование
Метрики
Общее количество запросов
Количество запросов обработаных с нарушением SLA
Количество запросов завершенных ошибкой
Логирование
Предусмотртеь логирование в достаточном объеме для решения возможных проблем

Масштабирование
Предусмотреть возможность увеличения количества реплик сервиса, возможно автоматическое при возразтании нагрузки

Надёжность
Circuit Breaker предотвращает каскадные отказы: если зависимость (Redis, PostgreSQL, Campaign Service) деградирует, сервис не тратит время на ожидание ответа, а сразу возвращает fallback.
