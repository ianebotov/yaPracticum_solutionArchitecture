Task 2. Проектирование RTB и интеграции с DSP (AdScale)

Краткое описание
В рамках задания необходимо спроектировать архитектуру критичного компонента — RTB-сервиса для интеграции с новой DSP-площадкой с соблюдением требований по времени отклика и надёжности.

Цель: выдержать 18 000 RPS (через 3 мес) при P95 ≤ 100 мс, 50 000 RPS (через 1 год) при P95 ≤ 80 мс.
