API Gateway для DSP-интеграции (AdScale)

API Gateway — единая точка входа для всех DSP-партнёров. Принимает внешние запросы по OpenRTB/HTTPS, выполняет аутентификацию, rate limiting, маршрутизацию и трансформацию протокола (HTTPS → gRPC) во внутренние сервисы.

Технология: Envoy Proxy или NGINX + Lua т.к. требуется высокая производительность
Масштабирование: допустимо горизонтальное
Целевая нагрузка: 18000 RPS (3 мес), 50000 RPS (1 год)

Функции API Gateway
Маршрутизация запросов и трансформация протокола

| Входящий путь | Целевой сервис | Протокол |
| /api/v1/bidding/** | Bidding Service | gRPC |
| /api/v1/statistics/** | Statistics Service | gRPC |
| /api/v1/campaigns/** | Campaign Service | gRPC |
| /api/v1/analytics/** | Analytics Service | gRPC |

Ограничение частоты запросов (Rate Limiting)
Защита от перегрузки одним DSP, настраиваемый параметр для DSP
Защита от суммарной перегрузки, настраиваемый параметр. 18000 RPS через 3 мес. и 50000 через год

Аутентификация и авторизация
Поддержка нескольких стандартов: API Key, OAuth2 возможность добавлять при необходимости

Масштабирование
Горизонтальное, добавление реплики при загрузке ЦПУ более 70%.
