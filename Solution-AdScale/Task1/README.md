Task 1. Архитектурная диагностика и целевое видение

Краткое описание
В рамках задания необходимо провести анализ текущей архитектуры SaaS-платформы компании AdScale, выявить проблемы и риски, разработать целевое архитектурное видение и задокументировать ключевые решения через ADR

Данные SaaS-платформы

Система - монолитный AdScale (C++/Go/Python/Node.js), PostgreSQL (1 инстанс), без кеша, очередей, контейнеризации.
Нагрузка на данный момент -  пик 15000 RPS, P95 = 110–120 мс при SLA ≤ 100 мс.
Нагрузка через 3 месяца - увеличение на 20% трафика (≈18000 RPS) без деградации SLA (подключение новой DSP-площадки)
Нагрузка через 1 год - увеличение в 2 раза (≈50000 RPS) при SLA  ≤ 80 мс.
Ограничения - бюджет ограничен, срок — 3 месяца, требуется непрерывность бизнеса, переписать систему полностью невозможно поэтому нужна постепенная миграция.
