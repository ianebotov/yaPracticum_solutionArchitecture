TO-BE целевая архитектура AdScale

AdScale — SaaS-платформа для размещения цифровой рекламы. Микросервисная архитектура с выделенными БД и кешем для критических сервисов. Доступно горезантальное маштабирование критических сервисов

Компоненты:
Bidding Service - сервис аукциона, ставок и бизнес-правил. Критичен по задержкам и несет максимальную нагрузку. Требуется независимое масштабирование
Campaign Service - Кампании, бюджеты. Требует частые изменений конфигураций
Statistics Service - Обработка событий кликов/показов. Требует высокой скорости на запись
Analytics Service - Отчётность, дашборды. Генерирует тяжёлые запросы на чтение
Financial Service - Списание, счета, балансы. Требует высокой согласованности и идемпотентности.
Advertiser Dashboard (BFF) - UI. Низкая критичность но требует независимых обновлений
Delivery Service - HTML/JS разметка
API Gateway - Маршрутизация запросов
Kafka - Данные по кликам, показам
Redis Cluster - Кеш
PostgreSQL - данные каждого сервиса
PostgreSQL Read Replica - реплика для чтения модулем аналитики
Service Mesh - рассмотреть возможность внедрения для взаимодействия между сервисами

Внешние системы:
DSP-партнёры
Платёжный шлюз (пополнение бюджетов)
