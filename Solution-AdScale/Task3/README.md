Task 3. Данные, масштабирование и отказоустойчивость (AdScale)

Краткое описание
В рамках задания необходимо спроектировать стратегии работы с данными и обеспечения масштабируемости и отказоустойчивости хранилищ.

Цель: выдержать 18 000 RPS (через 3 мес) при P95 ≤ 100 мс, 50 000 RPS (через 1 год) при P95 ≤ 80 мс.
