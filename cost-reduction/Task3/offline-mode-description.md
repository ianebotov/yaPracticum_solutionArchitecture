Механизм работы офлайн-режима и синхронизации данных

Офлайн-режим:
При отключении интернета, планшет кассира продолжает работать через локальный шлюз (Local Gateway) который хранит актуальную копию номенклатуры и цен что позволяет кассиру пробивать товары за наличные. Фискальный регистратор печатает чеки локально, через HAL, и не требует связи с облаком.
Безналичная оплата невозможна поскольку банковский терминал не может связаться с банком без интернета. Payment Gateway в облаке и поэтому при обрыве связи оплата картой недоступна.

Синхронизация при восстановлении связи
Когда интернет восстанавливается, Sync Service забирает с Local Gateway все прошедшие офлайн-продажи и записывает их в центральную базу данных Cloud DB. Это происходит автоматически. После синхронизации продажи становятся видны в SAP ERP, остатки товаров обновляются.
Local Gateway перенаправляет запросы в Cloud POS.
