Матрица решений Buy vs Build

| Возможность | Текущее решение | Стратегия | Обоснование |
|----------------|-----------------|-----------|-------------|
| POS / Пробитие чеков | Локальный толстый клиент | SaaS | Стандартная функция, не даёт конкурентного преимущества |
| SKU Matching | Ручная обработка в Excel (2 недели, 15% ошибок) | PaaS | Уникальный процесс M&A, требует кастомной логики |
| Программа лояльности | Ручная обработка в тетрадке | SaaS | Стандартная функция, имеются готовые решения |
| Приём товара | Локальные БД, ручной ввод | SaaS | Стандартная логистическая функция, имеются готовые решения |
| Расчёт премий продавцов | Локальный расчёт премий продавцам | PaaS | Специфика уникальна, много точек |
| ERP | централизованная ERP | централизованная ERP | оставляем без изменений |
| Promo Engine | единый движок промоакций (Promo Engine) | единый движок промоакций (Promo Engine) | Уникальное конкурентное преимущество, оставляем без изменений |
| Smart Fulfillment | собственная система омниканальной логистики | собственная система омниканальной логистики | главное конкурентное преимущество сети, оставляем без изменений |
| Инкассация | Ручной процесс | SaaS | Готовые решения инкассации (банковские сервисы) |
| Печать ценников | Локальный принтер | SaaS | Облачная печать ценников из SAP |
| Управление ИТ-инфраструктурой магазинов | Локальные серверы (500+) | IaaS | Перенос в облако |
