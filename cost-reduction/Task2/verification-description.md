Описание BPMN-процесса онбординга нового магазина VitaStore (TO-BE)

Участники процесса
Магазин, ИТ-инженер - Физическое присутствие в магазине, подключение к оборудованию
ИИ-сервис (Cloud), ИИ-сервис - Автоматическое сопоставление SKU по предварительно обученной модели
HQ: Team Data Integration, Товаровед - Ручное сопоставление по проблемным товарам
HQ: SAP ERP, Система ERP - формирование прайс-листов, рассылка обновлений

Основной поток процесса
ИТ-инженер, Прибыть в магазин(начало сценария)
ИТ-инженер, Подключиться к старой кассе
ИТ-инженер, Снять дамп БД товаров
ИТ-инженер, Загрузить файлы в ИИ сервис
ИИ-сервис, Получить файл
ИИ-сервис, Получить структуру и названия SKU
ИИ-сервис, Запустить ИИ-модель и сопоставить с эталонной базой
ИИ-сервис, Проверить соответствие, допустимое > 95%

XOR, Проверка соответствия по ИИ-модели
Ветка ДА, соответствие > 95%
ИИ-сервис, Автоматически подтверждает SKU
Ветка НЕТ, уверенность ≤ 95%
ИИ-сервис, Сформировать задание на ручного подтверждение

SKU передается в Team Data Integration - команду слияния баз данных
XOR, SKU подтвержден автоматичкски
Ветка ДА, SKU подтвержден автоматичкски
Данные автоматически передаются в SAP ERP
Ветка НЕТ, SKU НЕподтвержден автоматичкски
Список нераспознанных SKU передается товароведу
Товаровед, Выполняет ручное сопоставление
Данные передаются в SAP ERP

SAP ERP, Проверяет данные 
SAP ERP, Формирует прайс-лист и акционные предложения
SAP ERP, рассылает обновлённые прайс-листы по всем магазинам, включая новый.

Cloud POS, Получает актуальную номенклатуру
ИТ-инженер,активирует фискальный регистратор с новой номенклатурой 
ИТ-инженер, Выполнить тестовую продажу, для подтверждения корректной настройки
XOR, Результат теста
Ветка ДА, Тест пройден успешно, все готово для открытия магазина
Завершение сценария, магазин готов к открытию
Ветка НЕТ, Тест НЕпройден
ИТ-инженер, Эскалировать в Team Store Ops для решения проблем (решение не рассматриваем в данном документе)
Завершение сценария с ошибкой, Ожидание решения проблемы
